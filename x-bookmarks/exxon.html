Sales plays

Five plays built from the profiles above, the Datadog finding and Devin's Datadog integration. Each names who it is for and what to confirm before using it. Project links are from self-reported profiles and public pages, not from conversations with Exxon.

1. Datadog alert to Devin fix (incident-to-PR loop)

Who: Azmil Ab Aziz (GM Upstream IT, Kuala Lumpur); Michael Deal and Brad Harris as sponsors

Evidence: Datadog hosted a "Datadog Day" at ExxonMobil Tower, Kuala Lumpur, with a session titled "How ExxonMobil uses Datadog" and topics including AWS and Kubernetes (Datadog event page; the page gives no year, and Oct 2 falling on a Wednesday points to 2024). Devin has an official Datadog MCP integration and a webhook path that starts a Devin session from a Datadog monitor.

Play: Wire a low-severity Upstream monitor to Devin as a pilot: Devin pulls logs, traces and monitor state, finds the cause in code, and opens a PR with tests for a human to approve. Measure time to a reviewed fix, not time to diagnosis.

Opener: When a Datadog monitor fires on an Upstream application today, what happens between the alert and a merged fix, and who does that work at night?

Watch for: Datadog's own AI SRE (Bits Investigation, with its new Scout 1.0 model) overlaps on investigation. Keep the Devin lane on changing code and verifying it, and check Exxon's Datadog plan before promising anything.

2. Migration factory for the AWS program

Who: Paolo Biagi (Sr IT Director, IT Global Projects); Ryan Seager

Evidence: Biagi's profile cites a cloud migration of 3,000+ on-prem applications and servers to AWS inside a $150-200M annual portfolio. The Datadog Day agenda also references AWS and Kubernetes.

Play: Offer Devin for the tail of the migration: dependency upgrades, containerization, IaC changes and regression tests across many repos in parallel, with every change reviewable. Pair it with Datadog telemetry as the pass/fail check after each wave.

Opener: Of the 3,000+ applications, how many are lift-and-shift versus needing code changes, and how is the code-change group being staffed?

Watch for: Unclear how much of the 3,000 is still ahead. The profile is self-reported and undated, so confirm remaining scope first.

3. ERP consolidation and custom-code remediation

Who: Aaron Surber (Head of Record to Report IT); Bill Keillor (VP Business Transformation); Ryan Seager

Evidence: Surber describes consolidating multiple legacy systems into modern ERP platforms. The account research puts the SAP ECC6 estate at about 65M lines of custom code and a 2028 target for one S/4HANA instance. Keegan reposted Datadog's new SAP HANA Cloud integration two weeks before collection, so Datadog is moving into SAP estates.

Play: Position Devin on custom-code analysis, interface rewrites and test generation for the S/4HANA cutover, which is the playbook's account play. Ask whether Datadog's SAP HANA Cloud monitoring is in scope, since that gives a shared story with Datadog.

Opener: How much of the ECC6 custom code has been triaged into retire, rewrite or keep, and who owns the remaining remediation and testing?

Watch for: The ERP program may be owned by Global Business Solutions rather than IT, and that president is still unnamed. The IT-function filter did not reach those people.

4. Security backlog and zero trust follow-through

Who: Shazad Shafi (OT CISO); Bryan P. (CISO); Matthew Knies (Identity and Access Management)

Evidence: Biagi's profile cites Zero Trust for about 70K users and a SailPoint identity program. Knies leads IAM modernization. Shafi's profile describes protecting critical infrastructure. The 10-K, per the account research, puts cyber under the VP of IT with annual Audit Committee review.

Play: Lead with a contained security-fix pilot: Devin clears a defined vulnerability or hardening backlog in an isolated sandbox with a full audit trail. Security's approval criteria become the success criteria.

Opener: What would an autonomous agent have to show your security team, in its own isolated environment, before it could touch code near production?

Watch for: These leaders gate the deal more than they sponsor it. Bring the sandbox and audit story from the storylines before any pricing.

5. Agent layer beside the existing AI program

Who: Paolo Biagi; Darien Mathews (Head of IT, AI Business and Strategy)

Evidence: Biagi's profile cites a generative AI foundation built on copilots and LLMs. Mathews's title is AI business and strategy.

Play: Frame Devin as the step after an IDE assistant: whole tasks run end to end, not suggestions. Ask which assistant is deployed and what its measured effect has been.

Opener: Where have the copilots made individual developers faster but left the large jobs, like migrations and audits, untouched?

Watch for: The vendor is not named on the profile. Confirm it before comparing.
